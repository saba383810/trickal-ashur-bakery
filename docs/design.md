# エシュールのパン屋さん — ゲームデザインドキュメント

『トリッカル・もちもちほっぺ大作戦』の非公式ファンゲーム。
参照: 『星のカービィ ディスカバリー』ワドルディカフェ（お仕事系・時間内に稼ぐ）。

---

## 1. コンセプト

> **「手が足りない！」を、ほっぺで乗り切るパン屋さん。**

### デザインの柱

| 柱 | 内容 | 具体化 |
|---|---|---|
| ① 手が足りない忙しさ | 接客・焼成・防衛の 3 つが同時に要求される | 客は待てる時間に限りがあり、パンは焼かないと尽き、エルフィンは放置すると食べる |
| ② もちほっぺの手触り | 原作の核の操作感をゲームの中心の動詞にする | **ほっぺを引っぱって離す**（もちほっぺメーカーと同じバネ物理で ぷるんっ）。エルフィン撃退・客のごきげん回復・コミーを起こす・ネルの注文を見直す、のすべてがこの操作 |
| ③ リスクとリターンの判断 | 被害がその場で確定しない「ツケ」 | ツケはネルの接客成功で回収できる。追い払うか、接客を優先するかを常に迫られる |
| ④ 短く、何度も | 1 回 60〜120 秒の営業を辛さで選ぶ + エンドレス | ★評価・モード別のベスト記録・エンドレスの最長営業で「もう一度」を押させる |

### 想定プレイヤー / 環境

- sabanogames.com のあそび場に来る人。トリッカルを知っている人も知らない人も。
- PC（マウス + キーボードショートカット）とスマホ（タッチ・縦/横どちらも）。
- iframe（上部 44px のサイトバー付き）内で動作。インストール不要・ログイン不要。

## 2. 基本ルール

- モードは **チュートリアル / 微辛 / 中辛 / 辛口 / 激辛 / エンドレス** の 6 つ（§6）。解放条件はなく、最初から全部選べる。
- 制限時間内にお客さんの注文どおりのパンを渡し、代金を稼ぐ。
- 微辛・中辛・辛口・激辛: 時間（60 / 75 / 90 / 120 秒）終了時の **売上合計** で評価（★0〜3）が決まる。
- エンドレス: 会計するたびに残り時間が延び、時間切れまで続く。評価は同じく売上で★0〜3。営業できた時間も記録する（§6.1）。
- チュートリアル: 手順説明だけのモード。売上・★なし（§6.2）。

### 画面の流れ

```
タイトル「はじめる」 → モード選択
  ├ チュートリアル → 手順説明 → 「チュートリアル完了！」「微辛であそぶ」/「モードえらび」
  └ 微辛・中辛・辛口・激辛・エンドレス → 紹介パネル（パン・特殊キャラ・目標売上）「開店する」
       → カウントダウン → 営業 → リザルト「モードえらび」/「もう一度」
```

- チュートリアルは任意。未完了の間はモード選択で「はじめての方へおすすめ」として強調表示し、完了後は「クリア済み」。スキップしても完了扱い。
- ポーズメニューから「モードえらびにもどる」。チュートリアル中は「チュートリアルをスキップ」も出る。
- 記録は localStorage（キー `eshur-bakery:v4`）にモード id ごとのベスト売上・ベスト★・最長営業時間（エンドレス）を保存。モード選択の各カードにベスト★と売上（エンドレスは最長営業時間も）、タイトルに集めた★の合計（あつめた★ n / 15）を表示。
  辛口を足す前の保存（`v3`）は読み込み時に移す。前の「中辛」（id `medium`）はいまの「辛口」（id `spicy`）なので、その記録は `spicy` へ移す。
- モード選択のカードの左に顔を出す: チュートリアル = スピキ（しゃがみこんだ涙目の笑顔。体ごと出すので枠を少し大きく）/ 微辛 = コミー / 中辛 = エシュール / 辛口 = バター / 激辛 = エルフィン / エンドレス = ネル。チュートリアルとエンドレスは横いっぱい、その間の 4 つは 2×2（スマホ縦は 1 列）。
- 30 秒版の `eshur-bakery:v2` からは設定（音量・ミュート・キー表示）だけ引き継ぎ、記録は付け方が違うので捨てる。
- あそびかたに「モード」のページがある。チュートリアルをもう一度やるときもモード選択から（設定にボタンはない）。

### 画面構成（論理座標）

横持ち 1280×720 / 縦持ち 720×1280 の 2 レイアウトをビューポートの縦横比で自動切替。
基準より余る方向へ論理サイズを伸ばして、上下左右に余白を作らない（伸ばしすぎる時だけ余白）:

| 画面 | 伸ばす向き（上限） | 余りの使い道 |
|---|---|---|
| 横・iPad など 16:9 より縦長 | 縦（960 = 4:3 まで） | 4.5 割を店内、残りをショーケース（パンの枠も大きく）。かまどは細長くならないよう 60 まで |
| 横・横持ちのスマホ | 横（1600 まで） | 客席の間を広げ、作業場は真ん中に寄せる |
| 縦・縦長のスマホ | 縦（1600 まで） | 客席・ショーケース・オーブンに配る |
| 縦・iPad の縦持ち | 横（1000 まで） | 客席の間を広げ、パンの枠とかまどを少し大きく |

```
横持ち                                         縦持ち
┌──────────────────────────────────────┐     ┌──────────────┐
│ HUD: 時間 / 売上 / ツケ / ネル / フィーバー / ⏸ │     │ HUD          │
├──────────────────────────────────────┤     ├──────────────┤
│  客席1    客席2    客席3    客席4      │     │ 客1 客2 客3 客4│
│  [注文]   [注文]   [注文]   [注文]     │     │ [注文]        │
├══════════════ カウンター ══════════════┤     ├══ カウンター ══┤
│ ショーケース    │  トレー  │ オーブン×2〜3│     │   トレー      │
│ (パン棚 2段)    │ (最大4個) │            │     │ ショーケース   │
│ ←エルフィン侵入                        │     │ オーブン×2〜3  │
└──────────────────────────────────────┘     └──────────────┘
```

- 客席（3〜4）とオーブン（2〜3）の数はモードによる（§6）。
- エンドレスは時計の下にレベルの札を出し、延びた秒数を「+N秒」で表示。チュートリアル中はポーズボタンの下に「スキップ ▶▶」。
- お知らせ（エルフィン・ネル・フィーバーなど）は客の顔と吹き出しを隠さないよう、横持ちはカウンターの左（ショーケースの上・トレーの左）、縦持ちは看板の下・客の吹き出しより上に出す（`L.banner` / `L.bannerW`。収まらない文字は縮める。顔つきは左に顔の幅を空ける）。
- フィーバーのゲージ（スピキの顔 + 会計 1 回ぶんずつの目盛り）は、横持ちは HUD の右（ポーズの左）、縦持ちは 2 段目の右（チュートリアルはスキップボタンをよけて左）。

## 3. 操作とシステム

### 3.1 ショーケース → トレー → お客さん

| 操作 | 結果 |
|---|---|
| ショーケースのパンをタップ | 在庫 1 個をトレーにのせる（トレー上限 4） |
| トレーのパンをタップ | ショーケースに戻す（取り消し） |
| お客さんをタップ | トレーから **注文に含まれるパンだけ** を受け取る。残りはトレーに残る |
| お客さんを押したまま 14px 以上ずらす | 渡さずに **ほっぺを引っぱる**（§3.5） |

- 注文が揃ったら会計して退店。一部だけ渡した場合は注文吹き出しにチェックが付き、待ち時間が少し回復（+2 秒）。
- 1 個も合わないパンしか無い状態でタップ → 「ちがう…」（ほっぺを膨らませる）・待ち時間 -2 秒。連打の抑止。
- トレーが空でタップ → 何も起きない（ペナルティなし）。ネルだけは例外（§5）。
- **トレーはバッファ**: 2 人分をまとめてのせて順に渡す、が上達ポイント。

### 3.2 オーブン（焼成）

| 状態 | 表示 | 操作 |
|---|---|---|
| 空き | 扉が開いている | タップ → 焼くパンを選ぶメニュー → 焼成開始 |
| 焼成中 | 進捗リング | — |
| 焼き上がり | 金色に光る + 「チン！」・焦げるまでの残りゲージ（焦げないモードでは出さない） | タップ → 1 回分（3 個。食パンは 2 個）をショーケースへ |
| 焦げ | 黒煙 | タップで片付け（その回は全損） |

- 1 回の焼成で 3 個（食パンだけ 2 個）。焼成時間はパンごとに異なる（安いほど早い）（§6.3）。
- 取り出しを忘れると焦げる = 「客をさばくのに夢中で焦がす」がこのゲームの失敗の味。
  ただし最初は焦げない: 微辛・中辛は焦げず、辛口から入る（猶予は辛口 10 秒 → 激辛 8 秒。エンドレスは Lv3 から 8 秒）。取り出し忘れはいちばん多いつまずきなので、慣れてから足す。

### 3.3 お客さん（通常客）

- 空いた客席にランダム間隔で来店。来店間隔は営業が進むほど短くなる。注文は 1〜4 個（上限はモードによる）。間隔・注文個数の重み・待ち時間はモードごと（§6）。
- **注文の偏りを抑える**（`BALANCE.orderBias`。ネル・コミー・バターの注文も同じ）。同じパンばかり続けて頼まれて品切れになり、ほかのパンが余る、を防ぐ。パンは人気の重みで選び、次の倍率を掛ける:
  - 直近 2 件の注文と、いま選んでいる注文に入っている数ぶん ×0.5
  - 待っている注文に対して手持ち（在庫 + トレー + オーブンで焼いている・焼き上がった分）が足りなくなる数ぶん ×0.35
  - 直近 3 件すべてに入っていたパンは次の注文に入れない（同じパンが続くのは最大 3 件。全部のパンが続いているときは例外）
  - 品切れを完全には無くさない（焼いて補充する手間はゲームの一部）。全部のパンが少ないときは偏りでは避けられないので、先に焼いておくのが大事。
- **待ち時間ゲージ**（顔まわりのリング + 表情 3 段階。色だけに頼らない）。待ち時間 = 14〜16 秒（モードによる）+ 5 秒×個数。エンドレスはレベルで短くなる。0 で怒って退店 → 売上なし・コンボ途切れ。
- 支払い額:

```
支払い = Σ(パン価格) × (1 + 早さチップ) × (1 + コンボ) × ネル効果
  早さチップ: 待ち時間の残り > 66% → +20% / > 33% → +10% / それ以下 → 0
  コンボ   : 連続で怒らせずに会計した人数 × 5%（上限 +50%）
  ネル効果 : ネル接客成功後の 20 秒間 ×1.2（§5）
```

### 3.4 評価

- ★1/★2/★3 の目標売上はモードごと（§6）。数値はボットシミュレーション（§7）で調整する。チュートリアルは売上・★なし。
- 残り 10 秒で警告（BGM テンポアップ）。残り 4 秒からは新しい客が来ない（エルフィンは残り 5 秒から来ない）。
- エンドレスは閉店がなく、最後まで客もエルフィンも来る。時間が延びて残りが 10 秒を超えると BGM が戻り、13 秒を超えると次の警告をまた出せるようになる。
- リザルト: 売上内訳（パン代・チップ・コンボ・ネル効果・ツケ回収）/ 未回収ツケ / 接客数 / 最大コンボ / 怒らせた数 / 焦がした数 / 撃退数 / ネル接客 / フィーバーの回数と人数 / ほっぺ回数 / バターの援護回数 + エシュールのひとこと。エンドレスは営業時間（のびた秒数）とレベルも出す。
- ベスト売上を更新すると「ベスト更新！」、エンドレスで最長営業だけを更新すると「最長営業！」のバッジ。

### 3.5 ほっぺを引っぱる

作者の [もちほっぺメーカー](https://github.com/saba383810/moti_hoppe_maker) の移植。ゲーム全体の中心の動詞。

| 相手 | 離したときの効果 |
|---|---|
| 通常のお客さん・バター | 伸び ≥ 0.3 で待ち時間が **全回復**（1 人 1 回だけ） |
| コミー | 目を覚まして注文する（待ち時間は満タンから）（§4.4） |
| ネル | 注文をもう一度見せてくれる（待ち時間 -4 秒）（§5） |
| エルフィン | 伸び ≥ 0.72 で吹っ飛んで撃退。弱いとひるむだけ（§4.2） |

- 押して 14px 以上動かすと引っぱり、動かさずに離せば通常のタップ（渡す）。
- タイトル・モード選択・紹介・あそびかた・リザルト・チュートリアル完了に出てくるキャラもすべて引っぱれる（DOM 用コンポーネント `mochiChibi`）。重ねて置いたキャラ（タイトルでエシュールとネルの足もとにしゃがむスピキ）は、絵の透明な所を押すと下のキャラをつまめる。引っぱっている間は、伸びたほっぺが重なったキャラより手前に出る。
- 顔が出ていればどこでも引っぱれる（原作のオマージュ）。ゲームに効かない顔は見た目だけ伸びる:
  - キャンバスの飾りの顔（チュートリアルの吹き出しのエシュール、HUD のツケ・ネル・フィーバー、お知らせの顔）は `GameView.drawFace` で描き、`grabFace` でつまむ。つまんでいる間はお知らせを消さない
  - 来店中・帰り際のお客さん、追い払えない時のエルフィンも引っぱれる（効果なし）
  - チュートリアルの説明中も、顔を引っぱっても説明は進まない。顔を動かさずにタップしたときと、顔以外をタップしたときに進む
  - モード選択のカードの顔は、引っぱって離してもカードを押したことにしない
- 物理（もちほっぺメーカーと同じ）:
  - つまんだ点は指にバネで追従（ω80・ζ0.85）。伸びは tanh で頭打ち（上限 = 半径 28 × 1.2。頭の半径 50 に対して伸びすぎない長さ）。
  - ほっぺは外側へだけ伸びる。指のずれを、つまんだ側の真横から上下 60° までの範囲へ射影する（内側へ引くほど伸びが小さく、真内側では伸びない。`outward`）。
  - 離すとよく揺れるバネで戻る（9Hz・ζ0.19）。
  - 変形の減衰は (1-t)^3(6t²+3t+1) + つまんだ点まわりのリング状のふくらみ。
  - WebGL2 の頂点シェーダでスプライトのメッシュを変形。WebGL2 が無ければ変形なしで描く。
  - 伸びる範囲は目の下・口の外側のほっぺだけ（`MOCHI.eye` / `mouth` / `top` / `neck` のマスク）。目と口のまわり、前髪に隠れた額、首から下は動かさないので、目と口はゆがまず、額の輪郭が前髪の下から引き出されることもない。
  - 伸びた部分は絵を引き伸ばすので、顔のスプライトは画面の画素の 2 倍の細かさで描いてから変形する（ぼやけ・線のかすれを抑える）。
  - つまんでいる間の顔は「> <」の目（目尻に涙）と、上がわなわな波打つ開いた口（`pinched`）。涙は伸びるほっぺにかかるので、変形しない手前の層に描く。
  - 変形するのは顔の層（輪郭・ほっぺ・目・口）だけ。キャラは 3 層に分けて描き（`LAYER`）、体・後ろ髪・横の髪は変形した顔の下、前髪・眉・帽子・持ち物は上に、変形せずに重ねる。髪は伸びず、伸びたほっぺは横の髪の手前へ出る。
- 髪の揺れ（`MochiBody.hair`）: 2.4Hz・ζ0.18 のバネ。ほっぺを離すと伸ばしていた側へ振れ（伸びきって離すと毛先が 6 ほど）、2 秒ほどで止まる。離したあとのほっぺのぷるぷるは髪に伝えない（髪が細かく震えないように）。
  - つまんだまま急に引いた時、走り出し・立ち止まり（エルフィン）、渡して喜んだ時のはずみ（お客さん）でも揺れる。
  - 揺れの重みは部分ごとに変える（`SWAY`）。ほっぺの横に垂れる髪（触覚）×1.7・三つ編み・垂れ耳 ×1.3・ツインテール／ポニーテール ×1.2 は、根もとからの距離の 2 乗で横へずらしてしなるように描く（根もとはほとんど動かず毛先ほど大きく揺れる。横の帯に分け、帯ごとにつながる傾きのせん断をかける）。頭にくっついた後ろ髪 ×0.35・ヴェール ×0.3 は控えめなせん断、前髪は 0.15、アホ毛は根もとを軸にしなる。
  - `prefers-reduced-motion` なら揺らさない。

## 4. キャラクター別仕様

### 4.1 通常のお客さん

§3.3 のとおり。見た目は髪色・耳・帽子の組み合わせで量産する「妖精村の人たち」。（原作キャラを無断で客に使い回さない）

### 4.2 エルフィン（お邪魔）

**行動**

1. 画面端から入店し、ショーケースまで歩く（2.5 秒。この間も追い払える＝未然防止）
2. ショーケースに張り付き、一定間隔（モードにより 1.5〜1.9 秒）ごとにパンを 1 個食べる（在庫のあるパンから、高いものを優先）
3. 最大個数（モードにより 3〜5 個）食べるか、食べるものが無いまま 4 秒たつと退店。モードごとの間隔（§6）のあとにまた来る

- エンドレスはレベルが上がるほど、来る間隔・食べる間隔が縮み、たくさん食べる（§6.1）。

**ツケ**

- 食べたパンの価格が HUD の「ツケ」に加算。売上には入らない。
- ネル接客成功で回収（売上に加算）。終了時に残ったツケは **未回収** としてリザルトに赤字表示（スコア外）。

**追い払う = ほっぺを引っぱって離す**

| 操作 | 結果 |
|---|---|
| エルフィンを押して引っぱる | ほっぺが伸びる（バネ物理）。引っぱっている間は食べられない |
| 伸びが最大の 0.72 以上で離す | ぷるんっ と吹っ飛んで退店（撃退） |
| それより弱く離す / タップ | 「むにっ」→ 0.6 秒ひるむだけ。食べ続ける |

- 引っぱっている間は他の操作ができない = 「追い払う時間」がコスト。
- ネルの予告中〜退店まで、エルフィンは慌てて逃げ出し来店もしない（育て親が怖い）。ネルが帰って 5 秒後から戻ってくる。
- バターが座っている間はパチンコで撃たれる（§4.5）。

**設計意図**: 被害がツケとして「後で回収できるかもしれない」形で残るので、
「今すぐ追い払う」vs「目の前のお客さんを優先する」の判断が毎回発生する。

### 4.3 ネル（特殊キャラ）

原作: 世界樹教団の司祭長でエルフィンの育て親。完璧主義で、嫌いなものは「怠け者と滞納者」。
→ **女王様（エルフィン）のツケを清算しに来る** のは原作どおりの動機。接客は「完璧でなければ認めない」（§5）。

### 4.4 コミー（居眠り）

- 白髪の猫の子。注文 2 個（微辛は 1 個）・待ち時間 10 秒 + 4 秒×個数（エンドレスはレベルで短くなる）。
- 席に着くとすぐ居眠り（吹き出しは Zzz）。寝ている間は渡せず、待ち時間も減らない。
- **ほっぺを引っぱると起きて** 注文する（待ち時間は満タン）。
- 待ち時間が尽きても怒って帰らず、また眠る（席はふさがったまま）。

### 4.5 バター（見張り番）

- ミルクティー色の髪の犬の子（黄色いヘッドバンド・鈴の首輪）。注文 3 個（微辛は 2 個）・待ち時間 14 秒 + 4 秒×個数（エンドレスはレベルで短くなる）。
- 座って待っている間、入店中か食事中で、引っぱられていないエルフィンを **パチンコで撃つ**（着席 1 秒後に初撃、以後 2.2 秒ごと）。当たるとエルフィンは 1 秒ひるみ、食べる途中のタイマーがリセットされる。
- **設計意図**: バターに早く渡せば売上になるが、見張りもそこで終わる。あえて待たせてエルフィン対策に使う、というトレードオフ。

## 5. ネルの接客ルール「記憶接客」

1. **予告**（来店 6 秒前）: バナーで来店を予告し、客席を 1 つ空けておく（新規客はそこに座らない）。注文はまだ分からない。
2. **来店**: 注文（モードにより 3〜4 個。§6）が **最初の 3 秒だけ** 吹き出しに見え、そのあと [?] に伏せられる。待ち時間 16 秒 + 2.5 秒×個数。
3. **接客**: 覚えた注文をトレーにそろえてネルをタップする。
   - 判定は **トレーの中身と注文が完全一致**（種類と個数。並び順は問わない。余計なパンも不可）。
   - 一致しない → 「ちがいますよ？」・待ち時間 -4 秒。トレーはそのまま。
   - **トレーが空のままタップ、またはほっぺを引っぱる → もう一度注文を見せてくれる**（1.5 秒・待ち時間 -4 秒）。何度でもできるが高くつく。
4. **成功**:
   - エルフィンのツケを **全額回収**（売上に加算）
   - **ネルの祝福**: 成功後 20 秒間、獲得金額 ×1.2（HUD にゲージ表示・BGM 変化）
   - ネル本人の代金も支払われる（チップ・コンボは乗らない）
   - エンドレスは残り時間 +6 秒
5. **失敗**（待ち時間切れ）: ツケは回収されず残る。コンボも途切れる。

**設計意図**

- 通常客は「部分渡し OK・トレーから必要な分だけ取る」ゆるいルール。ネルだけは「一度に・ぴったり」。
  部分渡しを許すと総当たりで正解を探れて記憶の意味がなくなるので、一括判定にしている。
- 注文が見えるのは来店直後の 3 秒だけ。**ネルの来店に合わせて手を止めて見る** という判断そのものがゲームになる。
  忙しくて見逃した時のために「もう一度見せてもらう」救済がある（待ち時間で払う）。
- エルフィンを放置してツケを貯める戦略は「ネルに失敗すると全損」「パンが減って在庫切れ → 客を逃す」のでハイリスク。
  回収額はツケと同額（×1.2 にはしない）なので、わざと食べさせる方が得になる抜け道はない。

## 5.5 フィーバータイム

接客がうまく回るほど、ごほうびが来る。忙しさの合間に「何も考えずにどんどん渡せる」気持ちのいい時間を挟む（全モード共通。数値は `BALANCE.fever` と `StageDef.feverServes`）。

- **ゲージ**: 会計（注文を全部渡した時。コミー・バター・ネルも 1 回）ごとに 1 目盛り。`feverServes` 回（微辛 8 / 中辛 9 / 辛口 10 / 激辛 10 / エンドレス 9）で満タンになり、その場でフィーバー。フィーバー中の会計はゲージに数えない。
- **8 秒間**:
  - ショーケースのパンが減らない（在庫 0 でも取れる。棚の数字が虹色の ∞ になる）。戻しても増えない。
  - パンを 1 個だけほしいお客さんが、空いた席に次々来る（0.25 秒おき・席が空いて 0.15 秒で次。入店・退店もふだんより速い）。注文の偏りの調整（品切れ対策）はかけない。
  - 誰も待ちくたびれない（待ち時間が減らない → 渡せば必ず早さチップ最大）。焼けたパンも焦げない。
  - エルフィンは来ない（来ていたら逃げ出す。終わってから 3 秒は来ない）。ネル・コミー・バターは終わってから来る（予告できなかったネルは、終わってから 6 秒前の予告をしなおす）。
  - 時間制のモードは時計がそのまま進む。フィーバー中に 0 になっても閉店はフィーバーが終わってから（その間、時計は「延長！」になり、残り 10 秒の赤い点滅はやめる）。終わりの「フィーバーおしまい」とネルの予告は出さずに、そのまま「閉店！」。
  - エンドレスは残り時間が減らない代わりに、会計・ネルで延びない。
- **演出**: お知らせ「フィーバータイム！」（スピキの顔）・駆け上がる効果音・BGM がテンポ 150 の専用アレンジ・画面のふちが虹色に光る。
  虹色に輝くスピキ（ミームのオマージュ: しゃがんだままくるくる回り、横向きになるたびに色が変わる。明るさはそのままに色相だけを `color` 合成で塗り替える）が画面の外から次々出てくる。
  さわれない飾りで、操作するものには重ならないところだけを通る: 客の後ろを横切る / カウンターの前板を横切る（トレーより奥）/ 端の客の頭・吹き出しより外の画面の端から顔を出す・上から落ちてきて跳ねて帰る（HUD より奥）。`prefers-reduced-motion` では数を減らして回さない。
- ボットでは、1 回のフィーバーで初心者 約 1,000 G・上手い人 約 2,000 G（§7）。初心者でもどのモードでも 1 回は入る。

## 5.6 ブルミ（窓のおまけ）

せっかくの窓に、ときどきブルミが張り付く。気づいてタップすれば小さなごほうび（`BALANCE.burumi`、`StageDef.burumi` のモードだけ。チュートリアルには出ない）。

- 開店 12〜20 秒後に最初、その後は帰ってから 16〜28 秒おきに、左右どちらかの窓へ。0.45 秒で飛びついて 4.5 秒張り付き、0.5 秒で帰る。最後の 1.2 秒は「> <」の顔でずり落ちかける。
- 張り付いている間に窓をタップ（キー `B`）すると 150 G（売上の内訳「ブルミ」。ネルの ×1.2 はかけない）。リザルトに回数を出す。
- フィーバー中・閉店 1 秒前からは来ない（エンドレスは除く）。客・注文の乱数とは別の乱数で決めるので、来ても来なくても接客の流れは変わらない。
- 初めて来た時だけ、窓の横桟の下に「タップで +150 G」の吹き出し（ブルミ・客・注文には重ねない）。
- 窓の左上のガラスに、両手を顔の横に上げてへばりつく（下半身は横桟に隠れる。ガチャ画面で窓に張り付く場面のイメージ）。張り付いた瞬間は指を開いた手のひらをガラスに押しつける。
- 見た目は原作の特徴（金髪のボブに毛先がオレンジの低いツインテール・頭の双葉・白い花の髪飾り・白い丸い目・うずまきのほっぺ・白いフリルのトップスにオリーブ色のロングベスト）から描いたオリジナル。

### 6.1 エンドレス

- はじめの残り時間は 45 秒。会計（注文を全部渡した時）ごとに **1.2 秒 + 0.25 秒 × min(コンボ, 12)** 延びる（最大 4.2 秒）。ネルの記憶接客に成功すると +6 秒。残り時間の上限は 60 秒。
- 時間切れで終了。閉店（新しい客が来なくなる時間）はない。
- 20 秒ごとにレベル +1（最大 20）。レベルアップは効果音とバナーで知らせる。レベルが 1 上がるごとに:
  - 来店間隔 ×0.91（下限 1.9 秒）
  - 待ち時間 ×0.94（下限 ×0.5。通常客・コミー・バター。ネルは対象外）
  - エルフィン: 来る間隔 ×0.93（下限 3〜5 秒）、食べる間隔 ×√0.93（下限 1.1 秒）、最大個数は 3 レベルごとに +1（上限 7 個）
  - 注文個数の重み（1 / 2 / 3 / 4 個）: Lv1 5/4/1 → Lv2 4/4/2 → Lv3 4/4/3 → Lv4 3/4/3/1 → Lv5 3/4/4/2 → Lv6〜 2/4/4/3
  - Lv3 から焼けたパンが焦げるようになる（8 秒）。そのときオーブンで待っていたパンも、そこから 8 秒を数えはじめる。バナーでエシュールが知らせる
  - Lv5 からネルの注文が 1 個増える（4 個）
- ネル・コミー・バターは来るたびに次の来店が予約され、繰り返し来る（上の表の間隔）。
- リザルトには営業時間（のびた秒数）とレベルを出す。ベスト売上・ベスト★に加えて最長営業時間を保存する。

### 6.2 チュートリアル

- 独立したモードで、いつでも選べる。いつでもスキップできる（ポーズボタンの下の「スキップ ▶▶」/ ポーズメニューの「チュートリアルをスキップ」）。
- 時計・客の待ち時間・自動の来店を止めた World の上で、指示した操作だけを通す（指さしガイド）。客の出入り・呼んだエルフィンとバターは動く。オーブンは焼けるが焦げない。
- 手順:
  1. 1 個の注文をトレーにのせて渡す
  2. 2 個の注文をまとめて渡す
  3. ほっぺを引っぱってごきげん回復 → そのお客さんに渡す
  4. オーブンで焼いて取り出す
  5. エルフィンがつまみ食い（ツケの説明）→ ほっぺを強く引っぱって追い払う
  6. 居眠りのコミーのほっぺを引っぱって起こす → 渡す
  7. バターがエルフィンをパチンコで撃つ → バターに渡し、残ったエルフィンは自分で追い払う
  8. ネルの記憶接客（ぴったり渡してツケ回収）
  9. フィーバータイム（ゲージの説明のあと、その場で 8 秒間体験する。時計を止めていても席は回る）
- 終わると「チュートリアル完了！」パネル。「微辛であそぶ」（微辛の紹介パネルへ）/「モードえらび」。

## 7. バランス調整の方法

- ゲームロジック（`src/sim/`）は描画から分離した **決定的シミュレーション**（固定タイムステップ・シード付き乱数）。
- `tests/bot.ts` のボット（1 回に 1 操作・操作ごとに時間がかかる・エルフィンやオーブンに気づくまで遅れる・寝ているコミーと帰りそうな客のほっぺを引っぱる）を
  プレイモード（微辛・中辛・辛口・激辛・エンドレス）ごとに 3 段階の腕前で各 200 回走らせる: `npm run sim`。エンドレスは営業時間（900 秒で打ち切り）と平均レベルも出す。
  フィーバーの回数（0 回だった回数）とフィーバー中の売上、フィーバー以外の会計数も出す。`NO_FEVER=1 npm run sim` でフィーバーなしと比べられる。

- フィーバーなしでの売上（`NO_FEVER=1`）は、微辛が腕前によらず約 4,100 G（来店ペースで頭打ち）、中辛のふつう・上手いが約 7,400 G、激辛の上手いが約 22,100 G。フィーバーは時間制のモードで売上の 2〜4 割になる。
- ボットは焼き上がりにすぐ気づくので焦がさない（焦 0.0）。焦げの有無・猶予の差はシミュレーションに出ず、人間の取り出し忘れにだけ効く。
- エンドレスは、初心者 ★1（営業 1 分半ほど）、ふつう ★2（3 分ほど）、上手い人は ★3（5〜6 分）。フィーバーの 8 秒は残り時間が減らないぶん、営業時間が延びる。
- 注文の偏りの効果（`npm run sim` の「不足」= 注文が入った時点で手持ちでは足りなかったパンの割合、「連続」= 同じパンが続けて注文に入った最長件数の平均）。
  偏りを抑える前 → 後で（当時の 6 種の中辛〈いまの辛口の前身〉・150 秒の激辛で比較）、中辛の初心者 不足 27.5% → 21.4%・連続 4.0 → 2.7、激辛の初心者 不足 35.8% → 27.8%・連続 4.3 → 2.9、エンドレスの上手い 連続 5.9 → 3.0。
  残りの不足は全部のパンが少ないときに出るもの（ボットが先に焼かない）。
- 実機の手触りでの調整が前提。数値は `src/config/` に集約。

## 8. 演出・サウンド

- 絵: 公式素材は使わず全てコードで描画（§10）。トリッカルの SD 等身の雰囲気に寄せたオリジナルのちびキャラ: 縦長で濃い茶色のハイライトなしの小さめの目（顔の中心寄り）、目の下端より下・少し外の大きな平塗りのピンクのほっぺ（口と同じ高さ）、ω や八重歯の口。輪郭はこめかみが細く、ほっぺの高さでいちばんふくらむ下ぶくれのもち顔。線は原作のクレヨン（色鉛筆）のタッチに寄せ、赤茶の線と目に、ところどころ薄くかすれた細かい粒を混ぜた模様で描く（`crayon`。粒はキャラと一緒に拡大縮小する）。ドット絵は使わない。
- 線の太さをそろえる: 線の太さは頭の半径を基準にした単位なので、そのままだと HUD のアイコン・タイトルの奥のキャラ・窓のブルミ・説明の小さな全身のような小さな絵ほど線が細く薄くなる。頭の半径が画面上で 46px より小さいときは、輪郭や目のような線だけを最大 2 倍まで太らせる（`lineScale`。髪の筋・金の縁取り・白い線のような飾りの線は太らせない）。クレヨンの粒も画面上で 1.2px より細かくならないようにして、粒で線がかすれすぎないようにする（`setGrain`）。パンの輪郭もキャラと同じ赤茶のクレヨンの線で引き、吹き出しの小さなパンほど太らせる（巻きの筋はパンの色の細い線のまま）。
- 引っぱった時に絵柄を変えない: 伸ばした顔は輪郭なしで描いて変形し、変形した後の形のまわりに同じ太さのクレヨンの輪郭を付け直す（`MochiBody` の `outline`）。伸びたほっぺが元の輪郭にかぶさって、輪郭のないピンクのかたまりになることがない。
- モブの頬も名前のある子と同じ平たいピンクの丸（少し大きく、白いつやを 1 つ）にして、にじませない。フィーバーの虹色のスピキは、色を塗り替えても輪郭と目は元の赤茶の線のまま残す。
- ほっぺ: 引っぱっている間だけ WebGL2 で顔だけを変形して描く（§3.5）。横の髪は顔の輪郭より奥に描き、ほっぺが髪の手前に出る（髪がほっぺに刺さって見えない）。
- 手触り: ボタン・パン・客の反応はすべて 0.1〜0.6 秒の ease-out / spring。`prefers-reduced-motion` で揺れ・パーティクルを抑制。
- 向き: 歩くキャラは進行方向を向く。
- 効果音: WebAudio 合成（素材ファイル不要）。BGM: WebAudio の簡易シーケンサで明るいループ曲。残り 10 秒でテンポアップ（エンドレスで時間が延びて 10 秒を超えると戻る）。ネル効果中は専用アレンジ、フィーバー中はさらに速いテンポ 150 で 16 分のアルペジオが駆け上がるアレンジ（フィーバー > ネル効果 > 残りわずか > ふだん の順に優先）。
- 音量・ミュートは設定に保存。
- 衣装は原作の SD に寄せる: 脚は暗いタイツの短い一本脚、エシュールのベレー帽とネクタイのピンは青とオレンジのリボン付きの猫の顔、ネクタイは青、ポーチは白。エルフィンのマントは髪より奥に描き、横の髪は三つ編み（ひし形の髪留め）側を短く、反対側を裾まで長く。バターは白い丸襟と胸のリボンの黄色い A ラインのワンピースで、裾からピンクのフリルがのぞく。
- 髪の揺れは頭から遠いところ（毛先・アホ毛・しょっかく）ほど大きく、後ろ髪は小さく。ほっぺが伸びるのは目の下・口の外側だけで、目・口・額はゆがめない。スピキはつねられても、うるうるの涙目と泣き顔の口のまま（目はゆがめない層に描く）。

## 9. 技術設計

- Vite + TypeScript（strict）・フレームワークなし（もちほっぺメーカーと同じ構成）。描画は Canvas 2D（ほっぺの変形だけ WebGL2）、メニューは DOM。
- `npm run build -- --base=/entertainments/<slug>/app/` で動く静的出力（sabanogames の CI 前提）。
- 状態保存は localStorage（失敗しても動く）。タブ非表示で自動ポーズ。
- 言語: 日本語 / 한국어 / English。文言は `src/i18n/`（`ja.ts` が正本で、`ko.ts` `en.ts` は同じ形の型 `Strings`）。`T` が今の言語の文言で、`setLang` で差し替えて画面を作り直す。はじめは `navigator.languages`、選んだら保存。タイトル右上のボタンは押すたびに次の言語へ回り、ボタンには次の言語の名前をその言語で書く（日本語の画面に「한국어」）。韓国語は Jua を `M PLUS Rounded 1c` の次に置き、日本語の字形は変えない。チュートリアルの吹き出しは日本語は 1 文字ずつ、英語・韓国語は単語で折り返す。
- テスト: `npm test`（vitest 70 件。ほっぺ・コミー・バター・エンドレス・フィーバー・モード定義・注文の偏り・保存の移行・音の解禁を含むロジック単体）。
- 音: タブ／アプリを離れると AudioContext を止め、戻ったら起こす。iOS は戻っても `interrupted` のまま止まっていたり、`running` と言いながら鳴らなかったりして状態では見分けられないので、戻ってから最初の操作（どのボタンでも、画面のタップでも）で作り直す（BGM は新しい時計から刻み直す）。画面にいたまま止まった時（電話・アラームなど）は、操作のたびに起こし直し、1.5 秒たっても戻らなければ作り直す。
- 解像度: キャンバスとメニューの絵は端末の画素比（`devicePixelRatio`）に合わせて描く。上限は 3（スマホの多くが 3 倍。2 で止めると絵と文字がぼやける）。
  ページが拡大されている間（iOS は user-scalable=no を無視してピンチで拡大できる。sabanogames ではフレームの外側のページが拡大される）は、DOM は描き直されてくっきりするが canvas は引き伸ばされてぼやけるので、`visualViewport.scale` を掛けて細かく描く（4 倍・800 万画素まで）。拡大自体も `touch-action: pan-x pan-y` と `gesturestart` で止める。

## 11. 世界観・台詞の方針

- 舞台: 「エシュールのベーカリー」。女王様（エルフィン）の無銭飲食で赤字続き。プレイヤーは **教主** として店を手伝う。
- エシュール: 店主。チュートリアル・リザルトのひとこと担当。「パン屋」と呼ばれると拗ねる（大魔法使い・魔法講師でありたい）。
- 客: オリジナルの「妖精村の人たち」（原作キャラを客として量産しない）。原作キャラはエルフィン・ネル・コミー・バターが特別な役で来る（モードにより 1〜3 回、エンドレスは繰り返し）。
- スピキ（スピッキー）: ネットで生まれて公式に逆輸入された泣き虫の幽霊で、ネルのまねをしたシスター姿。顔は元のスピキにほぼそろえる（涙の粒がたまったうるうるの黒目、大きく開けた口、ぱっつん前髪、白い帯と金の星の黒い頭巾）。床にしゃがみこんだ姿もしるしなので、しゃがみ姿で描く（足の裏が低い `crouch`）。お店には来ず、モード選択のチュートリアルのカードに出る。
