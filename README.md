# エシュールのパン屋さん

『トリッカル・もちもちほっぺ大作戦』の **非公式ファンゲーム** です。公式とは関係ありません。原作に関する権利は各権利者に帰属します。

エシュールのベーカリーを手伝って、時間内にどれだけ売上を稼げるかの接客ゲーム。辛さ 4 段階のモード（★3 段階評価）と、会計で時間が延びるエンドレス、いつでも遊べて飛ばせるチュートリアルがあります。

- お客さんの注文どおりにパンを渡す（早いほどチップ、続けるとコンボ）
- オーブンでパンを焼いて補充する（辛口からは、取り出し忘れると焦げる）
- **ほっぺを引っぱる**: お客さんを押したままずらすと、ほっぺが伸びる（[もちほっぺメーカー](https://github.com/saba383810/moti_hoppe_maker) の移植）。離すとごきげんが満タンに（1 人 1 回）。原作と同じく、顔が出ていればどこでも引っぱれる（チュートリアルの吹き出しで話している最中も、HUD・お知らせ・メニューの顔も。ゲームに効くのは注文待ちのお客さんとエルフィンだけ）
- **エルフィン** がパンをつまみ食いしてツケにしていく → ほっぺを強く引っぱって離すと追い払える
- **ネル** の「記憶接客」: 注文は最初の 3 秒だけ。ぴったり渡せばツケを全額回収 + 20 秒間 売上 ×1.2
- **コミー** は居眠りしていて注文しない → ほっぺを引っぱると起きる
- **バター** は座っている間エルフィンをパチンコで追い払ってくれる（早く渡すと見張りも終わる）
- **フィーバータイム**: 会計するたびにスピキのゲージがたまり、満タンで 8 秒間のフィーバー。パンが減らず（∞）、パンを 1 個だけほしいお客さんが次々来る。誰も待ちくたびれず焦げもせず、女王様たちは終わるまで来ない。フィーバー中に時間切れになっても、閉店はフィーバーが終わってから（時計は「延長！」になる）。虹色に輝くスピキが画面の外から次々出てきて盛り上げる（さわれない飾りで、操作するものには重ならない）

設計の詳細は [docs/design.md](docs/design.md)。

## モード

タイトルの「はじめる」→ モード選択。最初から全部選べます。エルフィン・ネル・コミー・バターはどのモードにも来ます。カードの顔はスピキ（チュートリアル）・コミー・エシュール・バター・エルフィン・ネル。

| モード | 時間 | パン | オーブン | 客席 | 焦げるまで | ★1 / ★2 / ★3 |
|---|---|---|---|---|---|---|
| チュートリアル | — | 4 種 | 2 | 4 | 焦げない | なし |
| 微辛 | 60 秒 | 2 種 | 2 | 3 | 焦げない | 2,800 / 4,000 / 5,500 G |
| 中辛 | 75 秒 | 3 種 | 3 | 3 | 焦げない | 3,700 / 6,500 / 9,500 G |
| 辛口 | 90 秒 | 4 種 | 3 | 4 | 10 秒 | 4,300 / 7,900 / 12,000 G |
| 激辛 | 120 秒 | 7 種（全部） | 3 | 4 | 8 秒 | 6,500 / 11,500 / 19,800 G |
| エンドレス | はじめ 45 秒 | 6 種 | 3 | 4 | レベル 3 から 8 秒 | 4,500 / 13,500 / 43,000 G |

- フィーバーまでの会計数: 微辛 8 / 中辛 9 / 辛口 10 / 激辛 10 / エンドレス 9
- **チュートリアル**: 接客・ほっぺ・オーブン・エルフィン・コミー・バター・ネルの相手を 1 回ずつ、最後にフィーバータイムを体験。時計は止まっていて、いつでもスキップできる（ポーズボタンの下の「スキップ ▶▶」/ ポーズメニュー）。終わるまでモード選択でおすすめ表示
- **エンドレス**: 会計するたびに 1.2 秒 + コンボ×0.25 秒（コンボ 12 まで）延びる。ネル成功で +6 秒。残りは最大 60 秒。フィーバー中は残り時間が減らない（会計でも延びない）。20 秒ごとにレベルが上がり（最大 20）、客が増え・注文が多く・気が短くなる。レベル 3 から焼けたパンが焦げるようになる。ネル・コミー・バターは繰り返し来る。リザルトに営業時間とレベル、最長営業時間も記録
- タイトルに集めた★の合計（あつめた★ n / 15）を表示

## 操作

| 操作 | タッチ / マウス | キーボード |
|---|---|---|
| パンをトレーへ | ショーケースのパンをタップ | `1`〜`7`（並び順） |
| トレーのパンを戻す | トレーのパンをタップ | `Backspace`（最後の 1 個） |
| お客さんに渡す | お客さんか吹き出しをタップ | `A` `S` `D` `F`（左の席から） |
| ほっぺを引っぱる | お客さんを押したままずらして離す | `Shift` + `A` `S` `D` `F` |
| オーブン | オーブンをタップ → パンを選ぶ / 焼けたらタップ | `Z` `X` `C` → `1`〜`7` |
| エルフィンを追い払う | ほっぺをつまんで強く引っぱり、離す | `Space` 長押し → 離す |
| ポーズ | 右上のボタン | `Esc` / `P` |
| チュートリアルの説明を進める | 画面をタップ | `Enter` / `Space` |

タブを離れると自動でポーズします。スマホで別のアプリから戻ったときは、画面をタップすると音が戻ります。

## 開発

```sh
npm ci
npm run dev      # http://localhost:5173/
npm test         # ロジックの単体テスト（vitest）
npm run sim      # ボットによるバランス確認（モードごとの売上分布・★分布・フィーバーの回数と売上を腕前ごとに表示。エンドレスは営業時間とレベルも。NO_FEVER=1 でフィーバーなし）
npm run build    # 型チェック + 本番ビルド（dist/）
```

- 開発用ページ: `/preview.html`（キャラ・表情・パンの一覧）、`/thumb.html`（掲載用サムネイル 800×515）。本番ビルドには含まれません。
- 開発サーバーではコンソールから `app` で状態を触れます（本番ビルドでは無効）。
- 絵はすべて Canvas 2D のコード描画（ほっぺの変形だけ WebGL2。使えない環境では変形なしで描画）、音はすべて WebAudio の合成です（素材ファイルなし）。

## sabanogames への組み込み

[sabanogames](https://github.com/saba383810/sabanogames) の「あそび場」に、もちほっぺメーカーと同じ submodule 方式で載せています。

- submodule: `entertainments/trickal-ashur-bakery`（このリポジトリ）
- 公開 URL: `https://sabanogames.com/entertainments/trickal-ashur-bakery/`（CI が作るフレームページ。本体は `app/` 配下）
- CI は `npm ci && npm run build -- --base=/entertainments/trickal-ashur-bakery/app/` でビルドする
- 一覧のエントリは sabanogames の `site/src/data/entertainments.ts`、サムネイルは `docs/thumbnail.png` のコピー
  （`site/public/images/entertainments/trickal-ashur-bakery.png`）

このリポジトリを更新したら、sabanogames 側でポインタを進めてコミットする:

```sh
git submodule update --remote entertainments/trickal-ashur-bakery
```

サムネイルを差し替えたときは、sabanogames 側の画像もコピーし直して `image` の URL に `?v=N` を付ける（画像は 1 週間キャッシュされるため）。
